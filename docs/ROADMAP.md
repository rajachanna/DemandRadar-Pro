# Roadmap (not claims of implemented features)

- V0.1: local operator-only prototype; public read-only APIs, scoring, review, draft, CSV, owner Telegram, CI.
- Pilot: validate actual GitHub/HN response shapes and rate limits under a dedicated GitHub account; add source-specific terms and budget-validation policy.
- Hardening: server rate limiter, secret manager, SSO, backup/restore, multi-tenant separation, monitoring and independent pentest before public hosting.
- Integrations: add only permissioned RFP connectors; no unapproved scraping of job marketplaces.
- Conversion research: track qualified outreach and real replies with user consent, without invented success statistics.
